# Password Generator Application

A simple and secure Password Generator built using Python. This project generates strong random passwords containing uppercase letters, lowercase letters, numbers, and special characters.

## Features

* Generates random secure passwords
* Includes:

  * Uppercase letters
  * Lowercase letters
  * Numbers
  * Special characters
* User-defined password length
* Randomized character arrangement for better security
* Beginner-friendly Python project

## Concepts Used

* Python Functions
* Lists
* Loops
* User Input Handling
* `random.choice()`
* `random.shuffle()`
* String Manipulation

## How to Run

1. Install Python on your system
2. Save the file as `password_generator.py`
3. Run the program using:

```bash id="p7m3d2"
python password_generator.py
```

## Example Output

```text id="u1k9v4"
Enter password length: 10
Generated Password: A@7kLm#2Q!
```

## Purpose

This project is designed for Python beginners to practice randomization, functions, list operations, and password security concepts.
