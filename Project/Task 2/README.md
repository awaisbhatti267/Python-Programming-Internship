# Expense Tracker Application

A simple command-line Expense Tracker built using Python. This project helps users manage expenses by adding, viewing, and removing expense amounts through an interactive menu-driven system.

## Features

* Add new expenses
* View total expenses
* Remove expenses
* Input validation for invalid entries
* Prevents negative or excessive expense removal
* Beginner-friendly Python project

## Concepts Used

* Python Functions
* Global Variables
* `while` loops
* Conditional Statements (`if-elif-else`)
* Exception Handling with `try-except`
* User Input Handling

## How to Run

1. Install Python on your system
2. Save the file as `expense_tracker.py`
3. Run the program using:

```bash id="x8k2m1"
python expense_tracker.py
```

## Purpose

This project is designed for Python beginners to practice functions, loops, error handling, and basic financial tracking concepts.
