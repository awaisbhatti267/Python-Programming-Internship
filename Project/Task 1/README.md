# Python To-Do List Application

A simple command-line To-Do List application built using Python. This project allows users to add, view, and remove tasks through an interactive menu-driven interface.

## Features

* Add new tasks to the to-do list
* View all saved tasks with numbering
* Remove completed or unwanted tasks
* Input validation for incorrect entries
* Beginner-friendly Python project using loops, lists, and exception handling

## Concepts Used

* Python Lists
* `while` loops
* Conditional Statements (`if-elif-else`)
* `enumerate()` function
* List methods: `.append()` and `.pop()`
* Exception Handling with `try-except`

## How to Run

1. Install Python on your system
2. Save the file as `todo.py`
3. Run the program using:

```bash id="c3m4b1"
python todo.py
```

## Example Menu

```text id="9k2xv7"
1. Add a task
2. View tasks
3. Remove task
4. Exit
```

This project is perfect for Python beginners who want to practice programming fundamentals and build a small real-world application.
